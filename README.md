# سوريا دراما — النسخة التجريبية الأولى

موقع عربي متجاوب يعمل كدليل وأرشيف للمسلسلات السورية، مع بحث وتصنيفات وفلترة حسب سنة الإنتاج وصفحة تفاصيل لكل عمل.

## تشغيل محلي
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو خادم.

## الملفات
- `index.html`: بنية الموقع.
- `styles.css`: التصميم المتجاوب.
- `data.js`: بيانات المسلسلات.
- `app.js`: البحث والتصنيفات والتفاصيل.

## تعديل وإضافة مسلسل
افتح `data.js` وأضف عنصراً جديداً إلى مصفوفة `SERIES` بنفس بنية العناصر الموجودة. ضع رابط مشاهدة في `officialUrl` فقط إذا كان رابطاً رسمياً أو مرخصاً.

## ملاحظات مهمة
- البيانات الحالية عينة أولية لتجربة التصميم وليست أرشيفاً شاملاً أو قاعدة بيانات موثقة نهائياً.
- لا يحتوي المشروع على حلقات فيديو ولا يستضيف محتوى محمياً بحقوق النشر.
- يجب التحقق من دقة بيانات كل مسلسل وحقوق الصور والروابط قبل النشر العام.
- النسخة الحالية ثابتة (Static) ويمكن نشرها مجاناً على GitHub Pages أو Cloudflare Pages.
